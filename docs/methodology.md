# 方法设计

## 方法概述

本研究拟设计一种面向大语言模型奖励学习的稳定隐式超梯度求解方法。该方法由曲率保护、阻尼、对角预条件和自适应停止机制组成。

方法的暂定名称为：

> 基于曲率稳定化和自适应预条件的隐式超梯度方法

该名称用于描述拟研究方案，不代表已有公认算法名称。

## 线性系统

令：

\[
v
=
\nabla_\theta
\mathcal{L}_{\mathrm{outer}}
\]

隐式超梯度需要近似求解：

\[
Hx=v
\]

得到：

\[
x\approx H^{-1}v
\]

随后计算奖励模型的隐式梯度项：

\[
g_{\mathrm{implicit}}
=
-
\left(
\nabla^2_{\phi\theta}
\mathcal{L}_{\mathrm{inner}}
\right)x
\]

## 阻尼与曲率保护

由于非凸 PPO 损失的 Hessian 不一定正定，拟求解阻尼系统：

\[
(H+\lambda I)x=v
\]

其中 \(\lambda>0\) 为阻尼系数。

阻尼能够限制小特征值方向的放大，但也会引入超梯度偏差。因此，实验需要同时分析稳定性收益和近似偏差。

拟设置以下保护机制：

1. 检测非有限 Hessian 向量积；
2. 检测非正曲率；
3. 监控线性系统残差；
4. 求解停滞时提高阻尼并重新求解；
5. 对异常大的最终超梯度进行裁剪。

## 对角预条件

为降低不同参数层之间的尺度差异，构造正的对角预条件器 \(M\)，求解：

\[
M^{-1}(H+\lambda I)x=M^{-1}v
\]

候选预条件信息包括：

- Adam 优化器中的梯度二阶矩；
- 梯度平方滑动平均；
- Fisher 对角近似；
- 参数块级曲率尺度。

第一阶段优先使用实现成本较低的梯度平方滑动平均，并通过消融实验判断预条件器是否有效。

## 自适应停止

定义相对残差：

\[
\rho_k
=
\frac{
\left\|
v-(H+\lambda I)x_k
\right\|_2
}{
\|v\|_2+\varepsilon
}
\]

迭代满足以下任一条件时停止：

- 相对残差低于阈值；
- 残差连续若干步不再下降；
- 达到最大 Hessian 向量积预算；
- 检测到数值异常或非正曲率。

## 奖励尺度控制

奖励模型训练过程中可能出现输出尺度漂移。拟采用滑动统计对奖励或优势进行标准化：

\[
\hat r_t
=
\frac{r_t-\mu_r}{\sigma_r+\varepsilon}
\]

标准化不能破坏奖励模型参数到内层目标的必要梯度路径。统计量可以停止梯度，但标准化后的奖励仍需保留对奖励模型参数的依赖。

## 奖励模型更新

最终奖励模型梯度可以组合为：

\[
g_\phi
=
\alpha g_{\mathrm{supervised}}
+
\beta g_{\mathrm{implicit}}
+
\gamma g_{\mathrm{regularization}}
\]

其中：

- \(g_{\mathrm{supervised}}\) 用于拟合外部评分或偏好；
- \(g_{\mathrm{implicit}}\) 表示奖励变化对策略学习结果的影响；
- \(g_{\mathrm{regularization}}\) 用于限制奖励尺度和模型复杂度。

## 实施原则

算法改进前，需要先验证内层目标、外层目标和计算图的一致性。修复目标定义或梯度路径所得收益，应与新求解器所得收益分别报告。
