# 面向大语言模型强化学习的奖励模型双层优化与稳定超梯度方法研究

## 研究定位

本研究面向大语言模型强化学习训练，研究策略模型与奖励模型之间的双层优化关系，以及有限计算预算下稳定超梯度的估计方法。

研究主体是大语言模型训练。数学推理任务用于受控算法验证，城市交通决策任务用于应用验证。

## 研究背景

在基于人类反馈或外部评价的强化学习训练中，奖励模型负责评价大语言模型生成结果，PPO 等强化学习算法根据奖励信号更新策略模型。

传统方法通常分别训练奖励模型和策略模型，没有充分考虑奖励模型参数变化对策略学习结果的长期影响。双层优化通过建立策略模型和奖励模型之间的依赖关系，使奖励模型能够根据策略更新后的任务表现进行调整。

然而，双层优化中的隐式超梯度涉及 Hessian 向量积和逆 Hessian 向量积，可能面临以下问题：

1. 大语言模型参数规模大，无法显式构造 Hessian。
2. PPO 训练具有随机性，曲率估计可能存在较大噪声。
3. 非凸损失的 Hessian 不一定正定。
4. 固定迭代次数难以兼顾计算效率和求解精度。
5. 不稳定的超梯度可能导致奖励模型更新震荡或失效。

## 研究目标

1. 建立目标一致的大语言模型策略—奖励模型双层训练框架。
2. 验证奖励模型、PPO 内层目标和外层任务目标之间的梯度路径。
3. 研究带曲率保护、阻尼、预条件和残差控制的超梯度估计方法。
4. 分析超梯度误差、奖励模型质量和策略模型表现之间的关系。
5. 在数学推理和城市交通决策任务上开展实验验证。

## 研究内容

本研究主要包括以下内容：

- 大语言模型 PPO 与奖励模型的双层优化建模；
- 外部离散评价的策略梯度估计；
- 隐式超梯度的计算与正确性验证；
- 稳定超梯度求解器设计；
- 奖励模型优化与策略训练实验；
- 数学推理和城市交通决策应用验证。
