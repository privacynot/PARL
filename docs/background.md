# 研究背景

## 大语言模型强化学习

设输入为 \(x\)，大语言模型生成结果为 \(y\)，策略模型参数为 \(\theta\)。模型生成概率表示为：

\[
\pi_\theta(y\mid x)
\]

强化学习训练的目标是提高模型生成高质量结果的概率。与监督微调不同，强化学习可以利用正确率、偏好评分、规则评价或仿真结果等反馈信号。

## 奖励模型

奖励模型使用参数 \(\phi\)，对输入和生成结果进行评分：

\[
R_\phi(x,y)\in\mathbb{R}
\]

奖励模型可以通过人工评分、偏好比较、任务正确率或外部评价进行训练。

奖励模型不仅需要准确拟合标签，还需要为策略模型提供有效的优化方向。如果奖励模型存在偏差，策略模型可能利用奖励模型漏洞，获得较高预测奖励，但真实任务表现没有提高。

## PPO

近端策略优化算法通过限制新旧策略之间的变化幅度，提高强化学习训练的稳定性。其裁剪策略目标可以表示为：

\[
\mathcal{L}_{\mathrm{PPO}}(\theta)
=
-\mathbb{E}_t
\left[
\min
\left(
r_t(\theta)A_t,
\operatorname{clip}
\left(
r_t(\theta),1-\epsilon,1+\epsilon
\right)A_t
\right)
\right]
\]

其中：

\[
r_t(\theta)
=
\frac{\pi_\theta(a_t\mid s_t)}
{\pi_{\theta_{\mathrm{old}}}(a_t\mid s_t)}
\]

\(A_t\) 表示优势函数，\(\epsilon\) 表示裁剪范围。

在本研究中，PPO 负责更新大语言模型策略，奖励模型为优势估计提供奖励信号。

## 双层优化

策略模型和奖励模型之间存在依赖关系：奖励模型影响策略更新，而策略更新后的表现又能反映奖励模型是否提供了有效信号。

因此，可以将奖励模型优化表示为双层问题：

\[
\theta^*(\phi)
=
\arg\min_\theta
\mathcal{L}_{\mathrm{inner}}(\theta,\phi)
\]

\[
\min_\phi
\mathcal{L}_{\mathrm{outer}}
\left(
\theta^*(\phi),\phi
\right)
\]

内层使用奖励模型提供的信号训练策略模型，外层根据更新后策略的任务表现优化奖励模型。

## 主要挑战

本研究重点关注以下挑战：

- PPO 内层目标与超梯度计算目标是否一致；
- 外部离散评分如何转换为策略梯度；
- 如何在不显式构造 Hessian 的情况下计算超梯度；
- 如何处理随机曲率估计中的噪声和非正曲率；
- 如何在有限计算预算下平衡精度、稳定性和效率。
