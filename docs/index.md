# 面向大语言模型强化学习的奖励模型双层优化与稳定超梯度方法研究

## 研究定位

面向大语言模型强化学习训练，研究策略模型与奖励模型之间的双层优化关系，以及有限计算预算下稳定超梯度的估计方法。

## 研究背景

在基于人类反馈的强化学习训练中，奖励模型负责评价大语言模型生成结果，PPO 强化学习算法根据奖励信号更新策略模型。

传统方法一般分别训练奖励模型和策略模型，没有考虑到奖励模型参数变化对策略学习结果的影响。双层优化通过建立策略模型和奖励模型之间的依赖关系，让奖励模型能够根据策略更新后的任务表现进行调整。

但在双层优化中的隐式超梯度涉及 Hessian 向量积和逆 Hessian 向量积，可能面临以下问题：

1. 大语言模型参数规模大，无法显式构造 Hessian。
2. PPO 训练具有随机性，曲率估计可能存在较大噪声。
3. 固定迭代次数难以兼顾计算效率和求解精度。
4. 不稳定的超梯度可能导致奖励模型更新震荡或失效。

## 研究目标

1. 搭建训练框架，让奖励模型负责评价大语言模型的回答，并用评价结果指导大语言模型不断改进。
2. 理清奖励模型、PPO 策略训练和最终任务效果之间的关系，说明奖励模型的变化是怎样一步步影响大语言模型表现的。
3. 研究怎样更准确、更稳定地计算奖励模型对最终任务效果的影响，重点解决训练过程中曲率不稳定、数值容易放大和计算误差较大的问题。

## 研究内容

本研究主要包括以下内容：

- 大语言模型 PPO 与奖励模型的双层优化建模；
- 外部评价的策略梯度估计；
- 隐式超梯度的计算与正确性验证；
- 稳定超梯度求解器设计；
- 奖励模型优化与策略训练实验；
