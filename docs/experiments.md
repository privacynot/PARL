# 实验方案

## 实验目标

实验用于回答以下问题：

1. 超梯度计算是否正确？
2. 稳定化方法能否降低超梯度误差和训练波动？
3. 预条件方法能否减少 Hessian 向量积次数？
4. 超梯度改进能否提高奖励模型和策略模型表现？
5. 方法能否迁移到城市交通决策任务？

## 实验阶段

### 实验 A：受控正确性验证

在小规模可微双层问题上显式构造 Hessian，并使用直接线性求解结果作为参考。

评价指标包括：

- 超梯度方向余弦相似度；
- 超梯度相对误差；
- 线性系统相对残差；
- Hessian 向量积次数；
- 求解失败率；
- 运行时间和峰值显存。

### 实验 B：数学推理任务

使用具有明确标准答案的数学题训练和评测大语言模型。

数学任务具有评价客观、成本较低和便于重复实验等特点，适合验证双层优化和超梯度算法。

评价指标包括：

- 答案正确率；
- 答案抽取成功率；
- 输出格式合格率；
- 奖励模型评分误差；
- PPO 的 KL 散度；
- 超梯度范数和跨批次方差；
- 不同随机种子下的均值和标准差。

### 实验 C：城市交通决策任务

将交通状态、事件信息和约束转换为大语言模型输入，由模型生成结构化交通调控方案。

交通任务用于验证方法在外部仿真评分和复杂决策场景中的适用性。研究主体仍然是大语言模型训练，而不是传统小型网络交通控制。

评价指标包括：

- 结构化方案解析成功率；
- 交通规则和安全约束违规率；
- 平均延误；
- 平均和最大排队长度；
- 通行量；
- 停车次数；
- 跨交通流场景泛化表现。

## 对照方法

| 方法 | 作用 |
|---|---|
| 固定奖励模型与 PPO | 判断在线奖励优化是否必要 |
| 监督奖励模型与 PPO | 分离监督梯度和隐式梯度的贡献 |
| 固定步数普通 CG | 基础隐式超梯度对照 |
| 阻尼 CG | 验证阻尼作用 |
| 阻尼预条件 CG | 验证预条件作用 |
| 完整方法 | 验证全部机制的综合效果 |
| 有限步展开法 | 提供另一类超梯度估计参考 |

## 消融实验

分别移除以下组成部分：

- 曲率保护；
- 阻尼；
- 对角预条件；
- 自适应停止；
- 奖励尺度控制；
- 直接监督梯度；
- 隐式超梯度。

## 公平比较原则

所有方法应保持以下设置一致：

- 策略模型和奖励模型初始化；
- 内层和外层数据划分；
- 生成长度、温度和采样预算；
- PPO 更新次数和参数子空间；
- 外部评分协议；
- 最大 Hessian 向量积预算；
- 随机种子和硬件环境。

分别报告相同 Hessian 向量积预算和相同端到端运行时间预算下的结果。

## 数据划分

数据划分为：

1. 内层训练集：用于 PPO 策略更新；
2. 外层元训练或验证集：用于奖励模型更新和超参数选择；
3. 最终测试集：仅用于最终评价。

参与奖励模型更新的数据不能再作为最终测试数据。

## 统计报告

正式实验至少使用 3 个随机种子，报告均值、标准差和训练失败次数。关键比较应结合置信区间或适当的显著性检验，避免只选择表现最好的单次运行。
